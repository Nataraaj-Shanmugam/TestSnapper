Get Started

Installation

Get TestSnapper running in under a minute

Chrome Web Store Recommended

  1. Visit the TestSnapper Chrome Web Store page
  2. Click Add to Chrome
  3. Confirm by clicking Add extension
  4. The TestSnapper icon appears in your toolbar
  5. Click the icon to start recording

Developer Installation

  1. Clone from GitHub Repository
  2. Navigate to chrome://extensions in Chrome
  3. Enable Developer Mode (top right)
  4. Click Load Unpacked button
  5. Select the TestSnapper root folder
