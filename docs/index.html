TestSnapper records what you do in Chrome as numbered test steps, with field names, selectors and screenshots. Review them, then export to Word, PDF, CSV, JSON or Markdown.

Add to Chrome, it's free View source on GitHub

Open source under MIT. Runs entirely in your browser. Chrome 105 or later.

Steps someone else can follow

Manual test cases and bug reports take longer to write than to run. TestSnapper writes them while you run them.

  • Records every interaction

    Clicks, typing, dropdowns, checkboxes, form submits, key presses and page loads, in every frame. Pause and resume whenever you like.

  • Names fields the way people do

    "Email" rather than input#f-29a. Names come from labels, ARIA, placeholders and nearby text. If none is found, you're asked.

  • Stable selectors for automation

    Each step stores CSS and XPath selectors. IDs, test IDs, names and ARIA attributes are preferred, and auto-generated IDs are avoided.

  • Screenshots as evidence

    Capture on demand with Ctrl+Shift+S, on every page change, or on a timer. Choose PNG or high-quality JPEG.

  • Review before you share

    Rename, reorder, delete or add steps in card or table view, with undo. A privacy audit lists everything that was masked.

  • Optional API call log

    Record the XHR and fetch requests a page makes, or only the failed ones. Method, URL and status only, never bodies.

How it works

  1. Start recording

    Open the page you're testing, click the TestSnapper icon and press Start.

  2. Run your test

    Use the site as normal. Each action appears in the popup as you go.

  3. Review the steps

    Click View Steps to tidy names, add notes or insert manual checks.

  4. Export

    Pick a format and screenshot size. The file is named after the session.

Ctrl+Shift+S screenshot Ctrl+Shift+U pause or resume Ctrl+Shift+E stop Use ⌘ instead of Ctrl on a Mac.

Five export formats

One recording, whichever format your team or tool needs.

Word .docx
Session details and numbered steps with screenshots, ready to attach to a test plan.
PDF .pdf
The same layout on A4, for sign-off and audit evidence.
CSV .csv
Step, action, field name, value and URL, for spreadsheets and test-management imports.
JSON .json
Full session and step data, including selectors, to build automated tests from.
Markdown .md
A plain step list for tickets, pull requests and wikis.

Your recordings stay on your machine

Test environments are full of real accounts and real data. TestSnapper is built so none of it leaves your browser.

  • Sessions and screenshots are stored locally in Chrome. Nothing is uploaded and there is no analytics.
  • Passwords, PINs, card numbers, CVCs, SSNs, dates of birth and tokens are masked as they're recorded.
  • Screenshots are skipped while a password or payment field has focus.
  • No remote code: the Word and PDF libraries ship inside the extension.

Install

From the Chrome Web Store

The quickest way. Updates install automatically.

  1. Open TestSnapper in the Chrome Web Store.
  2. Click Add to Chrome, then Add extension.
  3. Pin the icon to your toolbar.
Add to Chrome

From source

Needs Node.js 18 or later.

git clone https://github.com/Nataraaj-Shanmugam/TestSnapper.git
cd TestSnapper
npm install
npm run build
  1. Open chrome://extensions and turn on Developer mode.
  2. Click Load unpacked and choose the dist folder.
