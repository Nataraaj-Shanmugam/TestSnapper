# Privacy Policy for TestSnapper

_Last updated: 26th November 2025_

TestSnapper is a Chrome extension designed to help users record interactions on webpages and generate automated test steps. We respect your privacy and are committed to handling data responsibly.

## 1. Data Collection
TestSnapper does **not collect, store, or transmit any personal data to external servers**.

The extension processes webpage content and user interactions **locally within your browser** only for the purpose of generating test steps. This includes actions such as clicking elements, typing text, and navigating between pages.

TestSnapper does not collect:
- Personally identifiable information  
- Authentication data  
- Financial or payment information  
- Personal communications  
- Health data  
- Location data  
- User browsing history  

Any interaction or webpage data accessed during recording is used **only in real time** to generate test steps and is **not sent anywhere**.

## 2. Local Processing
All processing happens on the user’s device.  
Recorded interactions are stored temporarily in the extension’s local storage or downloaded as files **only when initiated by the user**.

No data is transmitted to external servers.

## 3. Data Sharing
TestSnapper does **not**:
- Sell user data  
- Share data with third parties  
- Use data for advertising  
- Use data for analytics  
- Transfer data outside the user's device  

## 4. Permissions Use
TestSnapper uses the following Chrome permissions strictly to provide its core functionality:

- **activeTab & tabs** — to record interactions on the active page when the user starts recording.  
- **host permissions** — to read DOM elements on websites the user chooses.  
- **scripting** — to inject content scripts needed to capture interactions.  
- **storage** — to save temporary recording state locally.  
- **downloads** — to let the user export test steps or screenshots.  

These permissions do **not** allow the extension to collect data outside the user’s initiated recording session.

## 5. Third-Party Services
The extension does not use any third-party analytics, trackers, or remote code.  
All libraries (such as jsPDF) are packaged locally within the extension.
