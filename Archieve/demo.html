🎬 TestSnapper Demo

Test form with various input types for TestSnapper extension

How to Test

1. Install the TestSnapper extension
2. Click the extension icon and click "Start Recording"
3. Fill out this form and click submit
4. Stop recording and export to see captured field names and selectors

What TestSnapper Will Capture

  • Field names from labels, placeholders, and aria-labels
  • Robust CSS selectors (ID, data-testid, name, etc.)
  • Click events on buttons
  • Input/type events in text fields
  • Selection changes in dropdowns
  • Checkbox and radio button selections
  • Form submission
  • Automatic password masking (••••••••)
